入学要求

n 学习要求： 学生必须在国内参加中考并得到高中录取通知书。

n 年龄要求： 申请12年级不大于20周岁；11年级不大于19周岁；10年级不大于18周岁。

n 时间要求： 学生必须在澳大利亚读满16个月， 且不能倒读超过1年半的课程。

推荐入学方案

A． 精英型——精英私立中学

n 适应人群：初中毕业、高一／二在读；

n 语言要求：IELTS 4分/AEAS 36分以上，通过我们申请可豁免IELTS；

n 学 制：10-30周语言+1.5-3年高中；

n 担保费用：60-90万人民币；

n 学术要求：中学平均成绩在80分以上；

n 年龄要求：10年级不超过18周岁、11年级不超过19周岁。

方案解析：

澳大利亚精英私立高中一般都具有悠久的历史，学费、申请费也相当的昂贵。这类学校招收海外学生时，每年都有名额限制，因此，需要提前一年左右的时间递交申请，一般不接受中途插班的学生入读。部分中学甚至要求通过面试才能录取。

精英私立学校非常注重学生的全面发展，学校为学生提供各类文体活动与参与社会的机会。

B． 经济型——各州公立中学

n 适应人群：初中毕业、高一／二在读；

n 语言要求：IELTS 4分以上，通过我们申请可豁免I ELTS；

n 学 制：10-30周语言+1.5-3年高中；

n 担保费用：50-70万人民币；

n 学术要求：中学英语成绩在75％以上可豁免IELTS成绩；

n 年龄要求：10年级不超过18周岁、11年级不超过19周岁；

方案解折：

澳大利亚各州都有几十到上百所由政府出资的公立学校，分布在每州的各个地区，主要的招生对象为澳大利亚的当地学生。各州的教育部统一对海外学生进行招生，根据校园设施、师资力量等条件选择适合招收海外学生的公立中学，并根据情况决定各个学校每年招收海外学生的比例。各州的终考制度不同，部分州规定海外学生必须接受2年以上的学习时间，才能参加终考。

C． 大众型——国际型私立学院

n 适应人群：初中毕业、高一／二在读及在读三校生；

n 语言要求：IELTS 4分以上，通过我们申请可豁免IELTS；

n 学 制：10-30周语言+1.5-3年高中；

n 担保费用：50-70万人民币；

n 学术要求：被高中录取且英语成绩在75％以上可豁免IELTS成绩；

n 年龄要求：10年级不超过18周岁、11年级不超过19周岁。

方案解析：

国际型私立学院针对国际学生的不同背景，设置小班授课，入学门槛较低，适合不同学习层次的中学或三校生。学费相对较便宜。
