澳大利亚研究生教育

硕士学位课程（Master）

n 澳大利亚的硕士学位课程分为授课型（Coursework )与研究型（Research）两类。

n 授课型硕士课程的学习方式以授课为主，学生通过课程学习、完成学科作业及考试可获得学位；学制通常为1-2年，在学科领域上可以接受转专业申请。

n 研究型硕士课程以研究某专项课题为主，学生通过完成学科论文得到学位；其学制相对较长，入学要求较高且要求学生有相关学科的研究背景，但更容易申请到奖学金。

研究生文凭课程（Graduate Diploma）

澳大利亚大学的研究生文凭课程设置通常为1年，个别学校的部分专业为0.5年。完成课程后学生可获得研究生文凭，加读一定学分即可获得硕士学位。此类课程对于国内本科成绩不甚理想而又想入读一流大学的学生较为适合。

研究生证书课程（Graduate Certificate）

澳大利亚大学的研究生证书课程设置通常为0.5年，学生毕业后获得研究生证书，并可减免相应学分入读研究生文凭或硕士学位课程。此类课程对于国内本科成绩不甚理想及有丰富工作经验的大专毕业生较为适合。

入学要求

入读澳大利亚的大多硕士课程均要求申请人具有学士学位，部分专业要求有相关学习背景及工作经验。中国的大专毕业生可直接申请、或通过学位衔接课程入读部分院校的部分硕士课程。在语言要求方面，根据不同院校的不同专业的入学要求，申请人的IELTS成绩需在6.0-7.0之间；如果申请人的语言未达到相应课程的入学要求，则需在正式开课前参加学校语言培训中心的语言培训。

最佳申请时间

多数澳大利亚大学每年有春、秋两季入学，部分学校每年设3次开学时间。建议申请人在正式课程开始前8-12个月开始院校申请，尽早取得学校的Offer(留位通知书），并留有充足的时间作签证及行前准备。

推荐升学方案

A. 研究型——研究类硕士学位(Master by Research)

n 适应人群：国内本科／硕士毕业

n 语言要求：6.5/7.0

n 学 制：1-3年

n 担保费用：25万

n 学校专业：与本科或硕士研究背景相同

n 入学要求：在国内有较强的研究背景和论文发表，需要针对申请的专业递交专题报告（Research Proposal )

方案解析：

n 澳大利亚的大学大多都开设研究类硕士课程，但是开设的专业方向有所区别，根据教授研究的专业方向来决定；

n 申请者需要与申请专业方向的导师确定其方向是否相符，符合者方能递交申请；

n 在申请签证时，该类别的学生若申请的课程超过1年，只需要提供一年的生活费和学费的担保金即可，并且担保金只需提供3个月定期存款即可。研究类的硕士课程较易申请奖学金。

B. 五星型——课程类硕士学位（Master by Coursework）

n 适应人群：获得国内本科学士学位

n 语言要求：6.0/6.5

n 学 制：1-2.5年

n 担保费用：20-55万

n 学校专业：不完全受限制

n 入学要求：成绩优异（211工程大学毕业生成绩可略低）

方案解析：

n 部分课程类硕士学位能接受没有本科相关专业背景的学生入读，如：商科、信息工程、翻译、教育等

n 澳大利亚五星级大学的学术要求高，严进严出，适合在国内学术基础比较高的学生入读；

n 与其他学校相比，五星级大学的学费也略高。

C. 专业型——课程类硕学位（Master by Coursework）

n 适应人群：获得国内本科学士学位

n 语言要求：6.0/6.5

n 学 制：1-2.5年

n 担保费用：20-45万

n 学校专业：不完全受限制

n 入学要求：获得学士学位

方案解析：

澳大利亚大学各有其强势的专业领域，申请者可根据自己所选择的专业来决定学校。在专业型的学校中学习，能享受到高质量的师资与一流的学术氛围，并有机会获得相关的实习与工作机会。

D. 过渡型——过渡课程 + 硕士学位（Master)

n 适应人群：二年／三年制大专生及本科无学位者

n 语言要求：6.0

n 学 制：4个月—2年过渡课程+1—2年硕士学位

n 担保费用：30-60万

n 学校专业：受到限制，局限于商科、信息系统、大众传媒

方案解析：

n 中国大专毕业生可通过攻读4个月到2年的过渡课程，直接升入澳大利亚对口院校相关专业的硕士。

n 不同学校颁发的过渡课程的文凭不同：证书（Certificate）、文凭（ Diploma）和学士学位（Bachelor Degree）。

n 过渡课程对IELTS成绩要求比直接读硕士课程低，且能为学习硕士课程打下基础，学生最短在2年内获得硕士学位，甚至有可能额外获得本科学位，在申请移民时有额外的加分。

E. 快捷型——专科直升硕士学位

n 适应人群：三年大专生及本科无学位者及有一定工作经验者

n 语言成绩：6.0/6.5

n 学 制：1-2.5年

n 担保费用：17-35万

n 学校专业：受到限制，局限于会计、信息工程、国际贸易、金融等。

方案解析：

n 专科生直读硕士是一条通往高学历的捷径，学制短，费用也节省；

n 但是，专升硕的学生在选择学校和专业上会受到很大的限制。部分的院校要求大专生必须具有2-5年的工作经验方可申请直读硕士。
